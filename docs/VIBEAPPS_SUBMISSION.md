## Description
Everyday expense-line checker. Email a claim plus a public receipt URL to ceilinggate-claims@agentmail.to. Convex stores the claim. Firecrawl reads the receipt. GRANT if every line is at or under. REFUSE names the overage in dollars. App Forge lets a regular person spawn another honest micro-app (Tip Jar / Line Delta / Mask Chip) from the live panel.

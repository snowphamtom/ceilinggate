# App Forge

Recursive create layer for All Gas: **apps that create apps**.

## Judge demo
1. Open https://quirky-rhinoceros-204.convex.site/
2. Use CeilingGate Demo signature (GRANT → $1 REFUSE)
3. Scroll to **App Forge** → Forge micro-app
4. On box: `npm run forge -- --slug <slug> --title "…" --brief "…"` → `/workspace/forged-apps/<slug>`

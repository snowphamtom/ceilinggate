## What **C ≤ S** means (judge one-liner)

**Claim must not exceed Support.**  
Line by line: if the claimed amount is at or under the receipt (support) → **GRANT**. If any line is over → **REFUSE** (names the dollars).

That is the MAGPIE honesty rule Claim Check runs in public.

## Two-Gate (simple)

1. **Claim check** — does the ask stay inside what the receipt supports? (`C ≤ S`)
2. **Receipt check** — is there a clear support line for each claim line?

Both clear → **GRANT** + seal + Check ID. Over on either → **REFUSE**.
